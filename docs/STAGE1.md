# Этап 1. Основа — статус

## Готово
- Каркас: Svelte 5 + Vite 6 + vite-plugin-pwa (офлайн, установка на домашний экран), IndexedDB (idb).
- Контент в JSON по главам, схема `content/schema/chapter.schema.json`, описание `docs/CONTENT.md`.
- Автопроверки `npm run check`: схема, лексика только из пройденных глав, артикли, ссылки.
- Глава 1 (Schritte A1.1, Lektion 1, стр. 10–21): 6 уроков, 7 правил, 90 слов, 82 задания + 6 диалогов.
  | Урок | Учебник | Треки | Nicos Weg |
  |---|---|---|---|
  | 1 Hallo! Guten Tag! | A, стр. 10–12 | 1.1–1.8, 1.9, 1.10 | Folge 1 «Hallo!», Folge 3 «Tschüss!» |
  | 2 Ich heiße … | B, стр. 13 | 1.11, 1.12 | Folge 5 «Ich heiße Emma» |
  | 3 Woher kommst du? | C, стр. 14 | 1.13–1.15 | Folge 7 «Woher kommst du?» |
  | 4 Du oder Sie? Sprachen | C, стр. 14–15 | 1.16–1.18 | Folge 6 «Das ist Nico» |
  | 5 Wie schreibt man das? | D, стр. 16 | 1.19, 1.20 | Folge 4 «Von A bis Z» |
  | 6 Visitenkarte | E + Grammatik, стр. 17–19 | 1.21 | повторение серий 1–7 |
- Все 13 типов заданий, порядок урока правило → слова → задания → диалог → итог, ошибки возвращаются в конец урока.
- 6 маскотов SVG (лань, облачко, лисичка, обезьянка, альпака, сиба-ину), 5 эмоций, реплики по характеру.
- Тренажёры звуков: долгие/краткие, ei/ie, ü/ö, ch (ich/ach), r.
- Озвучка нейроголосами Edge (Катя на весь курс, Киллиан на мужские реплики диалогов), генерируется в GitHub Actions; если файла нет, голос телефона.
- Распознавание: Vosk small-de (офлайн, без Google) + встроенное в браузер на Samsung. Экран проверки качества в настройках.
- Репетитор: инструкции для проекта Claude, 5 режимов, сбор задания из прогресса и ошибок, разбор блока ИТОГ, слова в повторение.
- Напоминания: файл .ics с ежедневным событием (основной вариант) + тест веб-уведомлений.
- Повторение: простые коробки (1/3/7/14/30 дней) до перехода на FSRS на этапе 2. Экспорт/импорт прогресса.
- OpenCode: запускать на компьютере (облако закрыто для провайдеров), инструкция `docs/OPENCODE.md`.

## Проверить на телефонах (Антон и жена)
1. Открыть ссылку в браузере (Huawei: встроенный браузер или Firefox; Samsung: Chrome/Samsung Internet) → «Добавить на главный экран».
2. Настройки → «Распознавание речи» → «Начать», прочитать фразу. Записать процент узнанных слов на каждом телефоне.
3. Настройки → «Проверить веб-уведомления» и «Добавить в календарь».
4. Пройти главу 1.
