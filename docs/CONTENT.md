# Контент глав: формат и правила

Каждая глава — один файл `content/chNN.json`. Код менять не нужно: приложение подхватывает все `ch*.json` при сборке.
Строгая схема: `content/schema/chapter.schema.json`. Образец: `content/ch01.json`. Пустой шаблон: `content/schema/chapter.template.json`.

Проверка: `npm run check`. Она запускается и в GitHub Actions, поэтому глава с ошибками не опубликуется.

## Что проверяет `npm run check`
- Файл соответствует схеме (обязательные поля, типы заданий, варианты ответа).
- **Лексика только из пройденных глав.** Каждое немецкое слово в заданиях, диалогах, примерах и текстах для чтения должно быть в `words` этой или прошлых глав (с формами в `forms`) или в `names` (имена, города, улицы). Слова в минимальных парах не проверяются, это звуковые тренажёры.
- **Артикли.** `der/das/die + существительное` сверяются со словарём (`die` с формой мн. числа допустим, `aus der Schweiz` тоже).
- Ссылки: правила, слова и тренажёры звуков, на которые ссылаются уроки, существуют. В диалоге у каждой реплики есть верный ответ, у неверных есть объяснение.
- Предупреждения: меньше 12 заданий в уроке, меньше 6 разных типов, нет ссылки на Nicos Weg.

## Структура
```
chapter: id "chNN", number, title (нем.), titleRu, textbook, names[], words[], rules[], lessons[]
word:    id, de, ru, pos (noun|verb|adj|pron|func|phrase|country|language|num),
         article (der|das|die, обязательно для noun), plural (обязательно для noun, без артикля), forms[] (формы глагола)
rule:    id, title, text[] (3–6 строк по-русски), table {head[], rows[][]}, examples[{de, ru}] (2–3)
lesson:  id "chNN-lK", title, titleRu, goal, textbook {part, pages, tracks[]}, nicos[{title, url}],
         sound (id из sounds.json), rules[], words[] (6–12 id), exercises[] (12–15), dialog
```

## 13 типов заданий
| type | поля | что это |
|---|---|---|
| `choice` | prompt, options[2–4], answer, audio? | выбор ответа; `audio: true` — озвучить prompt |
| `article` | words[id] | слова в корзины der/das/die |
| `pairs` | pairs[[de, ru]] 3–6 | соединить пары |
| `order` | ru, answer[плитки], verbIndex?, extra? | собрать предложение; verbIndex подсвечивает глагол |
| `fill` | text с `___`, hint, answers[] | вписать форму, есть кнопки ä ö ü ß |
| `conjugation` | verb, ru, forms{ich, du, Sie…}, given[] | таблица спряжения |
| `dictation` | text, accept[]? | прослушать и написать |
| `listen_choice` | text, question, options, answer | прослушать и выбрать |
| `translate` | ru, accept[] (все верные варианты), selfCheck? | перевод с русского; selfCheck — ученик сверяет сам |
| `speak` | text, ru | повторить вслух, проверка распознаванием |
| `minimal_pair` | words[2], answer, ru[]? | что прозвучало: schon или schön |
| `dialog` | title, turns[{bot, ru, replies[{de, ok, feedback?}], keywords[[...]]}] | диалог с маскотом голосом или плитками; для голоса нужно найти хотя бы одно слово из каждой группы keywords |
| `reading` | title, lines[], questions[{q, options, answer}] | короткий текст и вопросы |

У любого задания могут быть `explain` (объяснение по-русски при ошибке) и `rule` (id правила для кнопки «Открыть правило»).

## Правила для авторов (люди и модели-помощники)
1. Тексты Schritte и Nicos Weg **не копировать**. Свои упражнения на ту же лексику и грамматику; на учебник ссылаемся страницами и треками, на Nicos Weg ссылкой.
2. Только лексика пройденных глав. Новое слово сначала добавить в `words` текущей главы.
3. У каждого существительного артикль и множественное число; у глаголов все формы, которые встречаются в заданиях.
4. Правила по-русски, коротко, 3–6 строк, 2–3 примера, таблица если помогает.
5. Порядок заданий в уроке: от простого (пары, выбор) к сложному (перевод, диалог). Минимум 6 разных типов. 2–3 `speak` на урок.
6. В `translate.accept` перечислить все естественные варианты (с тире и без, Tschüs/Tschüss).
7. Неверные реплики в диалоге — типичные ошибки русскоязычных, с объяснением в `feedback`.
8. После правки: `npm run check`, затем выборочная проверка немецкого Claude.
