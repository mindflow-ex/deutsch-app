# Помощники: OpenCode и бесплатные модели

## Где запускать
**На компьютере Антона.** Облачная среда Claude не пускает к провайдерам моделей (opencode.ai, OpenRouter закрыты), а Hugging Face и alphacephei.com закрыты для скачивания голосов и моделей. Поэтому:
- черновики глав делает OpenCode на компьютере;
- озвучку (Edge TTS) и модель распознавания (Vosk) собирает GitHub Actions при каждой публикации, на компьютере это делать не нужно.

## Установка (один раз)
```bash
curl -fsSL https://opencode.ai/install | bash     # или: npm i -g opencode-ai
git clone https://github.com/mindflow-ex/deutsch-app && cd deutsch-app && npm ci
opencode                                          # в интерфейсе выбрать бесплатную модель (/models)
```
Какие модели сейчас бесплатны, видно в `/models` в OpenCode (у OpenCode Zen и OpenRouter есть бесплатные варианты, список часто меняется). Платные ключи не нужны.

## Задание для помощника (шаблон)
```
Прочитай docs/CONTENT.md и content/ch01.json (образец качества).
Сделай content/chNN.json для главы NN «<название>» по программе:
<строка из таблицы «Программа по главам» в плане>
Учебник: части A–E, страницы <…>, треки <…> (номера сверю сам).
6 уроков по 12–15 заданий, минимум 6 типов в уроке, диалог в каждом уроке.
Тексты учебника не копируй, пиши свои фразы на ту же лексику.
После каждого урока запускай `npm run check` и исправляй ошибки, пока их не станет 0.
```
Потом Claude выборочно проверяет немецкий (артикли, падежи, естественность фраз) и вносит правки.

## Локальная модель (только в крайнем случае)
Если бесплатные облачные модели недоступны: маленькая модель через Ollama, щадящий режим:
```bash
OLLAMA_NUM_PARALLEL=1 OLLAMA_MAX_LOADED_MODELS=1 nice -n 19 ollama serve
# в OpenCode выбрать локальную модель, генерировать по одному уроку за раз
```
Ограничить потоки до 2–4 (`OLLAMA_NUM_THREADS=4`), по одной главе за запуск.
